## Reference Policy

- Prefer official Vue/Nuxt docs over blog-post folklore.
- If Nuxt 3 and Nuxt 4 behavior differs, state the version assumption.
- If a project uses compatibility flags, inspect `nuxt.config.ts` before making a migration recommendation.
