# generate-teammate Skill Spec & Verification Criteria

Verifies consistency with the official Claude Code documentation (Skills, Sub-agents, Agent Teams) and with the plugin-bundled agents that ship in this plugin.

## Critical correctness criteria

### C-1: No `model` parameter on the Agent invocation level

- [ ] No `model` parameter appears in `Agent({...})` calls in SKILL.md, approach-selection.md, team-patterns.md, execution-guide.md, or examples.
- [ ] No `| model |` column in pattern tables.

The model is resolved per Claude Code's hierarchy: env var → per-invocation override → subagent definition → main session. Documenting per-call model creates drift with definitions.

### C-2: Use `Agent` (not `Task`) tool name

- [ ] No `Task({` pattern in code examples.
- [ ] All teammate spawn examples use `Agent({...})`.

Task was renamed to Agent in v2.1.63; old `Task(...)` references work as aliases but new docs should use `Agent`.

### C-3: TaskCreate has no `addBlockedBy`

- [ ] `addBlockedBy` does not appear inside any `TaskCreate(...)` example.
- [ ] Task dependencies are set via `TaskUpdate({ task_id, addBlockedBy: [...] })`.

### C-4: `disable-model-invocation: true` in SKILL.md frontmatter

- [ ] SKILL.md frontmatter contains `disable-model-invocation: true`.

Prevents Claude from auto-invoking this skill on indirect prompts; explicit `/generate-teammate` only.

### C-5: Custom agent prerequisites documented

- [ ] SKILL.md notes that custom `subagent_type` values require an agent definition file (`~/.claude/agents/{name}.md`, `.claude/agents/{name}.md`, or plugin's `agents/`).
- [ ] SKILL.md states that the 14 generate-teammate routing agents ship with this plugin and require no setup.

### C-6: Agent Teams experimental flag documented

- [ ] SKILL.md mentions `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1` as a prerequisite.

### C-7: Plugin-bundled agents are self-contained

- [ ] No agent definition file in `plugins/elian-store/agents/` uses the `skills:` frontmatter field referencing external skills.
- [ ] No agent body relies on a non-built-in slash command being present (only optional hints).

This ensures the plugin works for users who install elian-store without requiring other plugins or user-level skills.
