Page Flow

Replace labels and triggers with the signed-off design brief. Keep page IDs consistent across flow, wireframe, and visual.

page-1: Overview Entry page. User sees the state of the work and chooses a task.
Row click -> page-2 detail
Primary action -> page-3 confirm
page-2: Detail Focused inspection or edit. Receives selected item from page-1.
Save or continue -> page-3 confirm
Back -> page-1 overview
page-3: Confirm Review, confirm, or result state. Receives selected items and decisions.
Confirm -> result on page-3
Return -> page-1 overview
Every page has a return path to page-1. No dead-end page is allowed.
